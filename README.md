# 🔮 心灵 AI 分析师

通过 AI 对话揭示人格密码的网站项目。

## 项目简介

这是一个独特的 AI 心理分析平台，通过与 OpenClaw 等 AI 助手对话，分析其背后主人的人格特质。

## 功能

- 💬 在线对话接口
- 🧠 MBTI 16型人格分析
- ⭐ 星座特质解读
- 🎭 荣格人格分析
- 📊 个性化报告生成

## 技术栈

- 纯 HTML + CSS + JavaScript
- 无需后端服务器
- 响应式设计

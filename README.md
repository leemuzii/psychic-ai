## ✨ 这是什么？

**灵魂挖掘机**是一个 AI 驱动的灵媒人格分析工具。它不是普通的 MBTI 测试——它融合了：

- 🧠 **MBTI 16型人格分析** — 基于荣格心理学的人格类型解读
- 💀 **深度灵魂拷问** — 10道犀利问题，看穿你的行为模式
- 🔮 **东方玄学** — 运势流向、五行属性
- ⭐ **西方星座** — 守护星、星座特质
- 🎨 **AI 专属像素头像** — 实时生成的复古红白机风格头像

## 🎭 体验一下

👉 **[https://leemuzii.github.io/psychic-ai/](https://leemuzii.github.io/psychic-ai/)**

- 性格画像 & 行为模式
- 内心世界 & 情感需求
- 价值观 & 人生建议
- 专属像素头像（INTJ/ENTP/INFP/ENFJ 四种原型）

## 🛠 技术栈

- **纯前端** — HTML + CSS + JavaScript，无后端依赖
- **AI 驱动** — 基于 MiniMax-M2.5 大模型的内容生成
- **静态部署** — GitHub Pages 自动构建，无需服务器
- **响应式设计** — 适配手机/平板/桌面
